# Believess Repo
A RootHide-based jailbreak repository.

![Believess Icon](https://raw.githubusercontent.com/believess0326/repo/main/CydiaIcon.png)

 📌 This repo is for **RootHide jailbreak** only.
 Supports: iPhone / iPad with RootHide, architecture:  `iphoneos-arm64e`

中文
这是一个面向 RootHide 越狱的插件源，仅适配 RootHide 环境，不支持传统（taurine / checkra1n 等）以及其他越狱。
本源收录自用、适配 RootHide 的调整插件，所有插件均经过基础校验；请自行甄别插件安全性，安装插件产生的一切风险由使用者自行承担。

English
This is a tweak repository built for the RootHide jailbreak. It **only works under RootHide**, not compatible with Taurine, checkra1n or other traditional jailbreaks.
This repo contains personally maintained tweaks compatible with RootHide. All packages have passed basic validation. You are responsible for any risks caused by installing tweaks from this repository.
